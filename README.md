# 数学启蒙小游戏

给小学低年级孩子用的数学小游戏，带中文语音朗读，适合在手机、平板或电脑浏览器里打开。

| 游戏 | 内容 |
|---|---|
| 🔢 认识数位（`number.html`） | 个十百千万；用计数器珠子演示"满十进一、退一当十" |
| 🔟 凑十法（`make-ten.html`） | 20 以内进位加法（凑十法）、退位减法（破十法），用十格框一步步引导；口算关会多出答错过的题 |
| 🕗 认识钟表（`clock.html`） | 整时、半时、几时几分；拖动分针时时针跟着联动 |

每个游戏都分关卡，每关集满 5 颗星解锁下一关，进度保存在浏览器里。

## 使用

直接双击 `index.html` 在浏览器里打开即可，不需要安装或联网。

- 语音朗读用的是浏览器自带的语音合成，第一次进入每个游戏时需要先点"点击开始"。
- 公共代码在 `common.js` 和 `common.css` 里。
